# Treinador de Códigos do Fort

Site simples para estudar os códigos dos produtos do Fort.

## Como usar

Abra o site, escolha uma categoria e um modo de estudo. Digite a resposta e pressione **Enter** ou clique em **Conferir**.

O site também permite embaralhar as perguntas, buscar produtos na lista completa e filtrar por categoria.

## Progresso

A pontuação fica salva no armazenamento local do navegador. Ela não é sincronizada entre dispositivos.

## Publicação

Este projeto pode ser publicado gratuitamente com o GitHub Pages:

1. Envie o arquivo `index.html` para a raiz deste repositório.
2. No GitHub, abra **Settings → Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Selecione a branch `main` e a pasta `/(root)`, depois clique em **Save**.
